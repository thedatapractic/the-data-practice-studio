# Template comparison: "The Data Mistake That Gets Companies Fined Millions (GDPR Explained by a Data Manager)"

Same topic, same core argument, six different structural templates — for Aji to compare and pick a winner before this goes into the real production pipeline as backlog #3.

**Core content is identical across all six** (this is a comparison of *shape*, not of ideas): the myth is that GDPR fines come from hackers; the reality is that most come from a governance failure — nobody in the organisation can say what personal data they hold, why they hold it, or when it should be deleted. All six draw on the same confirmed anecdotes (the data access request policy, the West Africa vaccination-dates story, the developer-years "client" field) rather than inventing new ones, per the standing rule to minimize references to real, identifiable current companies.
