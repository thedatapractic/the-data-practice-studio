# Cross-agent lessons

Lessons that affect **more than one agent**. When a correction in one agent's work carries a lesson for another (for example, Dan keeps flagging weak hooks, so Torch should open stronger; or Aji keeps reframing Linda's angle, so Torch should expect to sharpen the purpose), record it here **and** add it to each affected agent's own memory.

Each entry: `YYYY-MM-DD — [affects: Linda/Torch/Dan] — the lesson, as a rule.`

On its next task, each agent reads this file and copies any entry tagged for it into its own memory if it isn't already there, so the lesson sticks even in a fresh context.
