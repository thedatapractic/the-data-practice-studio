# Script templates

**Five templates, no more.** Every script picks exactly one before drafting starts, and states which and why in one line alongside the draft, so the choice is auditable later.

**Never default to whichever template the last video used.** The whole point of having five is that the channel should not read as one template with new words dropped in each week. If a video does not cleanly fit one of the five, flag it to Aji rather than forcing it.

The ten scripting rules in `CLAUDE.md` are the floor under all five. What differs between templates is the shape carrying those rules.

| Template | Use for | Model |
|---|---|---|
| [flagship.md](flagship.md) | Cornerstone teaching videos that walk the viewer through a whole argument, especially where a misconception must be unlearned first | Video 2 |
| [search-intent.md](search-intent.md) | Evergreen "what is X" / "is X worth it" searches where the viewer wants the answer now | — |
| [career-thread.md](career-thread.md) | Identity videos about the nature of the work itself, drawn from several chapters of a career | Video 1 |
| [transformation.md](transformation.md) | Career-change and journey videos, built on a before / obstacle / after arc | Video 7 |
| [listicle.md](listicle.md) | Shareable enumerable list videos, the one place where being "listy" is the genre, not a fault | Backlog #6 |

## Runtime

All five run to the **7–8 minute target, 10 minutes maximum** set on 2026-08-02. That supersedes the longer runtimes in the original template definitions, which were written against the earlier 15-minute format.

## History

The five-template system was agreed on 2026-07-20 and originally lived inside `CLAUDE.md`. It was moved into this folder on 2026-08-02 during the three-agent restructure, so Torch can select a template as a discrete file. The definitions are unchanged apart from the runtime note.

An earlier draft of this folder proposed a *myth-vs-reality* template. It has been removed to hold the five-template rule. If a myth-versus-reality shape is genuinely needed, raise it with Aji as a sixth rather than adding it quietly.
