# Script templates

The selectable structures Torch chooses from, one per video, based on the topic and Linda's brief. Every template still obeys the constitution in `CLAUDE.md` (the ten scripting rules, the AI-voice test, the voice). A template shapes the *arc*; the rules govern the *craft*.

Torch states at the top of each draft which template he chose and why.

| Template | Best for |
|----------|----------|
| [flagship.md](flagship.md) | Big "start here" / definitional topics that anchor a pillar |
| [myth-vs-reality.md](myth-vs-reality.md) | Topics where the audience holds a common wrong belief |
| [listicle.md](listicle.md) | "N signs / N mistakes / N things" shareable, scannable topics |
| [identity-story.md](identity-story.md) | Career-journey, day-in-the-life, war-story trust-building videos |

To add a template: create a new file here following the same shape, then it becomes selectable. This is part of the constitution, so add templates deliberately, not as a per-video tweak.
